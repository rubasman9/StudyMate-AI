# StudyMate AI

**مساعد تعليمي لإنشاء الاختبارات التفاعلية من الملفات الدراسية**

المشروع الختامي – رفع الإنتاجية بالذكاء الاصطناعي  
إعداد: ربى السمان | أكاديمية سدايا

## 1. نبذة عن المشروع

StudyMate AI مساعد تعليمي مخصص داخل ChatGPT، يساعد الطالب على تحويل الملفات الدراسية إلى اختبارات تفاعلية. يدعم أسئلة الاختيار من متعدد (MCQ) وأسئلة الصح أو الخطأ (True/False)، ويعرض سؤالًا واحدًا في كل مرة، ثم يصحح الإجابة ويشرحها ويحدد الموضوعات التي تحتاج إلى مراجعة.

- **المسار:** مساعد مخصص
- **التطبيق:** ChatGPT Project
- **الهدف:** تقليل الوقت اللازم لإعداد الاختبارات وتحسين تنظيم المذاكرة.

## 2. الملفات

| الملف | الغرض |
|---|---|
| `index.html` | صفحة تعريفية بالمشروع يمكن فتحها في المتصفح أو نشرها عبر GitHub Pages. |
| `STUDYMATE_RICE.md` | تعليمات المساعد بصيغة RICE، ويمكن نسخها إلى تعليمات ChatGPT Project. |
| `README.md` | شرح المشروع ومحتويات المستودع وطريقة تشغيل الصفحة. |

## 3. طريقة عرض الصفحة

لا تحتاج الصفحة إلى تثبيت برامج أو مكتبات:

1. نزّل ملفات المشروع أو افتح المستودع على GitHub.
2. افتح `index.html` في المتصفح لمعاينة الصفحة.
3. لنشرها عبر GitHub Pages: افتح إعدادات المستودع **Settings** ثم **Pages**.
4. ضمن **Build and deployment** اختر النشر من الفرع `main` والمجلد `/ (root)`، ثم احفظ.
5. بعد اكتمال النشر سيظهر رابط الصفحة في قسم Pages.

قد تختلف أسماء الخيارات قليلًا حسب واجهة GitHub الحالية.

## 4. طريقة استخدام المساعد الفعلي

1. افتح ChatGPT Project الذي أُعدّ للمشروع.
2. أضف تعليمات المساعد الموجودة في `STUDYMATE_RICE.md` إلى تعليمات المشروع.
3. ارفع الفصل الدراسي المطلوب بعد التأكد من أن سياسة الجهة تسمح برفعه.
4. اطلب إنشاء اختبار، ثم أجب عن الأسئلة واحدًا تلو الآخر.
5. راجع التصحيح والتفسيرات والموضوعات المقترحة للمذاكرة.

## 5. النتيجة المقيسة

- الوقت التقديري قبل استخدام المساعد: **30 دقيقة** لكل اختبار.
- الوقت التقريبي بعد استخدامه: **10 دقائق**.
- التوفير التقديري: **20 دقيقة لكل اختبار (نحو 67%)**.
- التوفير الشهري المتوقع عند 4–8 مرات استخدام: **80–160 دقيقة**.

هذه نتائج تقديرية مبنية على خط أساس تقديري وتجربة زمنية واحدة، وليست قياسًا إحصائيًا واسعًا.

## 6. حدود المشروع

- صفحة `index.html` صفحة تعريفية بالمشروع وليست واجهة تشغيل متصلة بالذكاء الاصطناعي.
- إنشاء الاختبارات والتفاعل معها يتم داخل ChatGPT Project وفق التعليمات.
- يجب مراجعة الأسئلة والإجابات بشريًا قبل الاعتماد عليها.
- لا ترفع بيانات شخصية أو ملفات سرية، وتحقق من سياسة الجامعة قبل مشاركة أي مادة دراسية.

## 7. تحسين مقترح

إضافة خيار مؤقت يحدد وقت الإجابة عن الأسئلة، لتقريب التجربة من الاختبارات الفعلية.
